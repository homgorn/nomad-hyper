# Internationalization (i18n)

## Goal
Support Russian + 9 more languages (EN, RU, ES, DE, FR, ZH, JA, KO, PT, IT) with LLM-assisted translation and 100% validation.

## Approach
1. **Framework**: react-i18next (admin frontend) + AdonisJS i18n (backend messages)
2. **Source strings**: English as primary, extracted to `locales/en/*.json`
3. **LLM translation**: Use local Qwen3.5 or cloud LLM to translate new strings
4. **Validation**: 
   - Automated: key parity check (all keys present in all locales)
   - LLM review: back-translation check (translate RU→EN, compare)
   - Human review: native speaker spot-check
5. **Community**: accept PRs with translations, validated by LLM + human

## What to translate
- UI strings (buttons, labels, messages)
- Documentation (docs/en, docs/ru, ...)
- Error messages
- Email templates
- Help text / tooltips

## Tools
- react-i18next + i18next-http-backend
- i18next-scanner (extract keys)
- LibreTranslate (self-hosted, offline) as fallback
- LLM (Qwen3.5) for draft translation
- Crowdin/Weblate (optional, for community)
