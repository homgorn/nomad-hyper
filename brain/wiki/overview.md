# Project Overview

## Summary
NOMAD Hyper is a self-contained, offline-first knowledge and education server. It orchestrates containerized tools (Kiwix, Kolibri, Ollama, Qdrant, etc.) via Docker. Extended with AI agents, IoT, LoRa/Meshtastic, SDR, solar power, voice stack, and Unsloth LoRA training.

## Key facts
- Upstream: Crosstalk-Solutions/project-nomad v1.35.1 (Apache-2.0)
- License: Apache-2.0
- Core: AdonisJS + React/Inertia + MySQL + Qdrant + Ollama
- Extended with: Claude Agent SDK, Qwen3.5, Home Assistant, Mosquitto, Grafana, ntfy, Matrix, and more
