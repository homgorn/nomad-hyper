# lan-survival Specification

## Purpose
LAN distribution and survival roadmap documentation.

## Requirements

### Requirement: LAN distribution documentation
The project SHALL document options for distributed deployment over LAN.

#### Scenario: LAN options
- WHEN a user reads the wiki
- THEN they find Ethernet/WiFi, distributed inference, shared Qdrant, Syncthing options

### Requirement: Survival roadmap
The project SHALL maintain a survival feature roadmap.

#### Scenario: Roadmap
- WHEN a user reads the wiki
- THEN they find a checklist of survival features (done/pending)
